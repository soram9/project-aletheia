# Project Aletheia

**Private intelligence. Permanent knowledge. Governed autonomy.**

> Hardware is temporary. Knowledge is permanent.

**Motto:** “Let nothing remain concealed.”

Project Aletheia is the long-term development of a personal AI system built around privacy, durable knowledge, and user control. Its intended direction is local-first operation, portable records, and a modular design that can survive changes in hardware, models, vendors, and platforms.

## Public repository scope

This repository contains public-facing project documentation. It describes intent, principles, and planned work; it does not establish that an operational AI system, offline capability, or security control has been implemented or validated.

Private knowledge, deployment details, and operational records belong in separately controlled storage. Public documentation should explain design rationale without exposing the environment it describes.

## Intended direction

- Keep the user in control of knowledge, access, and consequential actions.
- Prefer local processing and make external service use explicit.
- Preserve important records in open, portable formats.
- Replace individual components without losing accumulated knowledge.
- Distinguish verified facts from inference, speculation, and unverified claims.
- Document decisions so future tools and models can understand their rationale.

These are design goals, not statements of completed implementation.

## Publication and participation

Keep public discussions focused on general design and documentation. Do not include private files, credentials, deployment endpoints, or personal information in issues, pull requests, or attachments. Review [SECURITY.md](SECURITY.md) before sharing material.
